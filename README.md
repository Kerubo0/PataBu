# PataBu
#PataBu — Find Your Bus in Real Time

PataBu is a simple, low-tech solution to a big problem in African public transport:
not knowing when the next bus will come, how much it will cost, or if there’s space.

Instead of forcing passengers to download many different apps for different SACCOs, PataBu uses tools everyone already has — USSD and SMS — to deliver real-time transport information
#The Problem

Public transport users often face:
  Long waiting times with no updates
  Unclear or changing fares
  Confusing or undocumented routes
This uncertainty wastes time, money, and energy.

#The Solution
PataBus is a central system that multiple bus SACCOs can plug into.
Passengers:
  Dial a USSD code
  Enter their current stop and destination
Receive an SMS with:
  Bus number plate
  SACCO name
  Fare
  Route stops
  Estimated arrival time
Drivers or conductors update bus status using simple SMS or USSD commands.
