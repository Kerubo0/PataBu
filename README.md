# PataBu
#PataBu — Find Your Bus in Real Time

PataBu is a simple, low-tech solution to a big problem in African public transport:
not knowing when the next bus will come, how much it will cost, or if there’s space.

Instead of forcing passengers to download many different apps for different SACCOs, PataBu uses tools everyone already has — USSD and SMS — to deliver real-time transport information
